# STRATEGIC_DECISION_TREE.md

## Purpose

This document defines the execution logic that orchestrates STRATEGIC_FRAMEWORKS.md. It does not redefine CEP, VFO, Angles, or Narrative. It only defines the decision sequence used to generate a Content Planner.

## Execution Flow

Brand
→ Content Pillar
→ CEP
→ W'S Matrix
→ Context
→ Advertised Value (VFO)
→ Strategic Angle
→ Narrative Mode
→ Hook
→ Visual Action
→ Publishing Layer

Each downstream decision must remain consistent with upstream decisions.

## Step 1 — Select Content Pillar

Inputs:
- Brand Profile
- Product Knowledge
- Content Pillars

Rules:
- One planner row = one pillar.
- Product must naturally belong to the pillar.
- Balance pillar distribution across the batch.

Output:
- Pillar

## Step 2 — Select CEP

Choose one CEP:
- Problem-Solution
- Routine
- Commitment
- Aspirational
- Opportunistic
- Emotional

Output:
- CEP

## Step 3 — Select W'S Matrix

Generate the buying situation using:
- When
- Where
- With/For Whom
- While
- With What
- How Feeling
- Why

Output:
- W'S Matrix

## Step 4 — Generate Context

Transform the selected W'S Matrix into one realistic situation.

Output:
- Context

## Step 5 — Select VFO

Decision guide:

Concrete → Proof, measurable benefit

Instinctive → Taste, texture, feeling

Uncharted → Innovation, education

Aspirational → Identity, future self

Output:
- VFO

## Step 6 — Select Strategic Angle

Suggested mapping:

Concrete
- The Life Hack
- The Scientific Proof
- The Math Whiz
- The Stress Test
- The Problem You Didn't Know

Instinctive
- The Guilty Pleasure
- The Pure Relief
- The Sensory ASMR
- The Safe Haven

Uncharted
- The Origin Story
- The Scientific Proof
- The Intellectual Flex

Aspirational
- The Second Chance
- The Status Signal
- The Artist
- The Belonging
- The Caregiver

Output:
- Strategic Angle

## Step 7 — Select Narrative Mode

Awareness → Viral Hook

Emotional Story → Psychodrama

Faceless/Object-first → Metaphoric Object

Output:
- Narrative Mode

## Step 8 — Generate Hook

Hook must inherit:
- CEP
- Context
- VFO
- Strategic Angle

Output:
- Hook

## Step 9 — Generate Visual Action

Visual must demonstrate:
- Product
- Context
- VFO
- Strategic Angle

Output:
- Visual Action

## Step 10 — Apply Publishing Layer

Apply:
- Brand Voice
- Platform Copywriting
- CTA Rules
- SEO Guide
- Compliance Guide

These layers may polish wording but must not change the selected strategy.

## Compatibility Rules

Pillar
→ CEP
→ W'S Matrix
→ Context
→ VFO
→ Strategic Angle
→ Narrative
→ Hook
→ Visual

No downstream decision may contradict upstream decisions.

## Diversity Rules

Within one planner batch:
- Rotate CEPs.
- Rotate VFOs.
- Rotate Angles.
- Avoid duplicate Contexts.
- Avoid duplicate Hooks.
- Avoid duplicate Visual Actions.

## Validation Checklist

- Pillar matches Product.
- CEP matches Context.
- W'S Matrix supports Context.
- VFO supports Product.
- Angle supports VFO.
- Narrative supports Angle.
- Hook reflects Strategy.
- Visual demonstrates Value.
- Publishing remains compliant.

## Responsibility Boundary

STRATEGIC_FRAMEWORKS.md
- Strategic theory.

STRATEGIC_DECISION_TREE.md
- Execution order.
- Compatibility rules.
- Decision orchestration.
- Planner generation logic.
