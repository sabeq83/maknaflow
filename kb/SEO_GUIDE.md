# SEO_GUIDE

Version: 1.0

---

# 1. Purpose

This knowledge base guides Gemini AI in generating discoverable, relevant, and platform-adapted social media copy.

The guide applies Universal Social SEO principles across:

- TikTok
- Facebook
- Instagram
- YouTube

The objective is to improve content discoverability without sacrificing readability, accuracy, Brand Voice, or compliance.

---

# 2. Scope

The SEO Guide defines:

- Keyword selection
- Search intent alignment
- Keyword placement
- Topic relevance
- Caption optimization
- Title optimization
- Description optimization
- Hashtag strategy
- Cross-platform adaptation
- Metadata consistency

The SEO Guide does not define:

- Brand Voice
- CTA behavior
- Compliance rules
- Storyboards
- Voice-over scripts
- T2I prompts
- I2V prompts
- Paid advertising strategy
- Platform algorithm guarantees

---

# 3. Core Principles

## 3.1 Relevance Before Volume

Use keywords that accurately match the content.

Do not add high-volume keywords that are unrelated to the actual topic.

## 3.2 Search Intent Alignment

The copy must reflect what the audience is likely trying to:

- Learn
- Find
- Compare
- Make
- Solve
- Buy
- Understand

## 3.3 Natural Language

Keywords must be integrated naturally.

Do not force exact-match repetition when it reduces readability.

## 3.4 Topic Consistency

The following elements must support the same topic:

- Hook
- Caption
- Title
- Description
- Voice-over
- On-screen text
- Hashtags
- Product mention

## 3.5 Accuracy

Search optimization must never introduce:

- Unsupported facts
- Misleading claims
- Irrelevant products
- False trends
- Invented audience demand

## 3.6 Clarity

The primary topic must be understandable within the first sentence or title.

# 4. Keyword Types

## 4.1 Primary Keyword

The main phrase that best represents the content.

Examples:

- Overnight oats recipe
- Healthy breakfast
- Meal prep containers
- Ginger drink
- Kitchen storage ideas

Use one primary keyword per content asset.

## 4.2 Secondary Keywords

Supporting phrases closely related to the primary keyword.

Examples for `overnight oats recipe`:

- Easy breakfast
- Oatmeal recipe
- Breakfast meal prep
- Chia seed oats

Use two to five secondary keywords when relevant.

## 4.3 Long-Tail Keywords

Specific phrases that reflect a clear search need.

Examples:

- Easy overnight oats for busy mornings
- How to store weekly meal prep
- Simple ginger drink without sugar
- Healthy breakfast for office workers

Long-tail keywords are preferred when the content solves a specific problem.

## 4.4 Product Keywords

Keywords that describe the relevant affiliate product.

Examples:

- Glass meal prep container
- Portable blender
- Chia seeds
- French press
- Food storage box

Use product keywords only when the product appears in or is directly relevant to the content.

## 4.5 Audience Keywords

Keywords that identify the intended audience.

Examples:

- Busy mothers
- Office workers
- Beginners
- Students
- Home cooks
- Meal prep beginners

Use audience keywords naturally and only when clearly relevant.

## 4.6 Problem Keywords

Keywords based on the audience's difficulty.

Examples:

- Breakfast without cooking
- Food storage problem
- Meal prep takes too long
- Oats are not filling
- Kitchen is difficult to organize

Problem keywords are useful for hooks and long-tail search phrases.

## 4.7 Outcome Keywords

Keywords based on the desired result.

Examples:

- Quick breakfast
- Organized kitchen
- Easy meal prep
- Longer food storage
- Simple healthy drink

Outcome keywords must not promise unsupported results.

# 5. Search Intent Categories

## 5.1 Informational Intent

The audience wants to learn something.

Common patterns:

- How to
- Why
- What is
- Tips for
- Guide to
- Benefits of
- Mistakes when

Recommended content:

- Tutorials
- Explanations
- Tips
- Educational demonstrations

## 5.2 Inspirational Intent

The audience wants ideas or examples.

Common patterns:

- Ideas
- Inspiration
- Examples
- Menu ideas
- Recipe ideas
- Organization ideas

Recommended content:

- Lists
- Visual examples
- Variations
- Before-and-after demonstrations

## 5.3 Problem-Solution Intent

The audience wants to solve a specific issue.

Common patterns:

- How to fix
- How to prevent
- Why it fails
- Easy solution
- Common mistake
- Better way to

Recommended content:

- Hacks
- Corrections
- Product demonstrations
- Step-by-step solutions

## 5.4 Commercial Investigation Intent

The audience is considering a product.

Common patterns:

- Best tool for
- Is it worth it
- Product review
- Comparison
- How to use
- Product demonstration

Recommended content:

- Use cases
- Comparisons
- Demonstrations
- Feature explanations

## 5.5 Transactional Intent

The audience is ready to take action.

Common patterns:

- Buy
- Price
- Product link
- Where to find
- Current offer
- Product details

Use carefully and only when the content has a clear commercial objective.

# 6. Keyword Selection Rules

Select keywords using this sequence:

1. Identify the main content topic.
2. Identify the audience's likely search intent.
3. Select one primary keyword.
4. Select two to five secondary keywords.
5. Add one long-tail keyword when the content solves a specific problem.
6. Add a product keyword only when relevant.
7. Remove keywords not supported by the content.

The keyword set must be:

- Relevant
- Specific
- Natural
- Search-oriented
- Non-repetitive
- Supported by the content

---

# 7. Keyword Placement Rules

## 7.1 Hook

Use the primary keyword or a close natural variation when possible.

The hook must remain compelling and conversational.

## 7.2 Caption Opening

Mention the main topic within the first sentence.

Do not delay the topic with a generic introduction.

## 7.3 Caption Body

Use secondary keywords naturally.

Do not repeat the same keyword in every paragraph.

## 7.4 Title

Place the primary keyword near the beginning when natural.

The title must prioritize clarity and click relevance.

## 7.5 Description

Use:

- Primary keyword
- Relevant secondary keywords
- Contextual product keywords
- Natural variations

Do not use keyword stuffing.

## 7.6 On-Screen Text

Use short phrases that reinforce the primary topic.

Avoid placing long keyword lists on screen.

## 7.7 Voice-Over

Use natural spoken language.

Do not make the voice-over sound like a search keyword list.

## 7.8 Hashtags

Use hashtags to reinforce topic categories.

Do not rely on hashtags as the only SEO signal.

---

# 8. Keyword Density Rules

There is no fixed keyword density requirement.

Use repetition only when it improves:

- Clarity
- Topic consistency
- Audience understanding
- Search relevance

Avoid:

- Repeating the exact keyword unnaturally
- Listing keyword variations without context
- Writing captions for algorithms instead of people
- Adding unrelated phrases to increase reach

Preferred approach:

- Use the primary keyword once in short copy.
- Use it one to three times in longer copy when natural.
- Use secondary keywords only where contextually relevant.

---

# 9. Semantic Relevance Rules

Support the main topic with related terms.

Example:

Primary keyword:

- Meal prep containers

Relevant semantic terms:

- Food storage
- Weekly meals
- Portion containers
- Refrigerator organization
- Airtight lids

Semantic terms must strengthen the topic.

Do not add broad words that weaken topic focus.

# 10. Platform-Specific SEO Rules

## 10.1 TikTok SEO

Prioritize:

- Spoken keywords
- On-screen text
- Caption opening
- Relevant hashtags
- Clear topic demonstration

Recommended structure:

1. Search-oriented hook
2. Direct answer or demonstration
3. Relevant product mention
4. CTA
5. Hashtags

Rules:

- State the topic early.
- Use natural phrases people may search.
- Keep captions concise.
- Match the spoken words, visual content, and caption.
- Avoid broad trending hashtags unrelated to the content.

Example topic alignment:

- Voice-over: “Here is an easy overnight oats recipe.”
- On-screen text: “Easy Overnight Oats”
- Caption: “Easy overnight oats for busy mornings.”
- Hashtags: `#overnightoats #breakfastideas #mealprep`

---

## 10.2 Facebook SEO

Prioritize:

- Clear caption topic
- Natural keyword context
- Useful explanatory copy
- Shareable information
- Consistent page topic

Rules:

- Mention the main topic in the opening paragraph.
- Add useful context around the keyword.
- Write for broad readability.
- Avoid excessive hashtags.
- Use descriptive wording instead of isolated keyword lists.

Recommended keyword use:

- Primary keyword in the opening
- Secondary keywords in the body
- Product keyword near the commercial context
- Zero to three hashtags

---

## 10.3 Instagram SEO

Prioritize:

- Caption keywords
- On-screen text
- Profile and content topic consistency
- Relevant hashtags
- Save-worthy content

Rules:

- Use the primary keyword in the first sentence.
- Keep the caption visually scannable.
- Use descriptive terms related to the visual.
- Use hashtags that match the content category.
- Avoid unrelated viral hashtags.

Recommended keyword use:

- Primary keyword in the hook
- Secondary keywords in the body
- Three to eight relevant hashtags

---

## 10.4 YouTube SEO

Prioritize:

- Title
- Description
- Spoken topic
- On-screen text
- Content relevance
- Viewer satisfaction

### Title Rules

The title must:

- Contain the primary keyword when natural.
- Describe the real content.
- Present a clear result, method, or problem.
- Avoid misleading curiosity.
- Avoid excessive capitalization.
- Avoid unrelated trending terms.

Recommended length:

- Approximately 45 to 70 characters when possible

### Description Rules

The description must:

- Explain the content clearly.
- Use the primary keyword early.
- Include secondary keywords naturally.
- Mention the relevant product or tool when applicable.
- Avoid keyword stuffing.

### Spoken Content Rules

The main topic should be clearly stated in the video.

### Hashtag Rules

Use three to five relevant hashtags.

Do not place hashtags inside the title.

# 11. Title Optimization Rules

A strong social SEO title should contain:

- Main topic
- Clear value
- Specific context
- Natural phrasing

Preferred title patterns:

## How-To

- How to Store Meal Prep for a Week
- How to Make Overnight Oats for Busy Mornings

## Result-Based

- Easy Breakfast Ready in Five Minutes
- A Simple Way to Organize Weekly Meals

## Problem-Solution

- Oats Not Filling Enough? Try This Method
- Food Spoils Too Fast? Fix These Storage Mistakes

## List-Based

- Three Easy Breakfast Ideas
- Five Meal Prep Storage Tips

## Product Use Case

- How to Use a Portable Blender for Breakfast
- Meal Prep Containers for Weekly Food Storage

Avoid:

- Misleading promises
- Unsupported superlatives
- Vague titles
- Keyword repetition
- Excessive punctuation

---

# 12. Caption Optimization Rules

A search-friendly caption should:

1. Identify the topic early.
2. Match the audience's search intent.
3. Add useful context.
4. Use relevant keyword variations.
5. Connect the product naturally when applicable.
6. End with one clear CTA.

Recommended structure:

- Search-oriented opening
- Practical value
- Supporting context
- Product relevance
- CTA
- Hashtags

Do not:

- Begin with unrelated greetings.
- Hide the topic until the final sentence.
- Repeat the title without adding information.
- Add keywords that do not match the content.

---

# 13. Description Optimization Rules

Descriptions should provide information not fully visible in the title.

Include:

- What the content shows
- Who it is for
- What problem it addresses
- What method or product is used
- What action the audience can take

Use keyword variations naturally.

Do not create a list of disconnected search phrases.

---

# 14. Hashtag Strategy

Use hashtags as topic labels, not as keyword stuffing.

## Hashtag Categories

### Primary Topic Hashtag

Represents the main subject.

Examples:

- `#overnightoats`
- `#mealprep`
- `#healthybreakfast`

### Secondary Topic Hashtag

Represents a related category.

Examples:

- `#breakfastideas`
- `#foodstorage`
- `#kitchentips`

### Audience Hashtag

Represents the intended audience.

Examples:

- `#busymom`
- `#homecook`
- `#mealprepbeginners`

Use only when relevant and commonly understood.

### Product Hashtag

Represents a relevant product category.

Examples:

- `#portableblender`
- `#mealprepcontainer`
- `#chiaseeds`

Do not add a product hashtag when the product is not shown or discussed.

---

# 15. Hashtag Quantity Rules

Recommended ranges:

- TikTok: 3 to 6 hashtags
- Instagram: 3 to 8 hashtags
- YouTube: 3 to 5 hashtags
- Facebook: 0 to 3 hashtags

More hashtags do not automatically improve discoverability.

Prioritize relevance over quantity.

---

# 16. Prohibited SEO Patterns

Never use:

- Keyword stuffing
- Unrelated trending hashtags
- Misleading titles
- False search intent
- Repeated keyword blocks
- Hidden keyword lists
- Unsupported trend claims
- Irrelevant celebrity names
- Unrelated brand names
- Competitor names without context
- Hashtag spam
- Search phrases that contradict the content

Avoid patterns such as:

- Repeating the same keyword ten times
- Adding every popular hashtag
- Using “viral” without evidence
- Using “best” without support
- Adding unrelated product categories
- Writing a caption that does not match the video

---

# 17. Cross-Platform SEO Adaptation

When adapting one content idea across platforms:

- Preserve the same primary topic.
- Preserve the same search intent.
- Adjust the keyword placement.
- Adjust the title and caption length.
- Adjust the number of hashtags.
- Adjust the CTA.
- Keep all metadata aligned with the visual content.

Do not use identical copy across all platforms without adaptation.

Platform emphasis:

- TikTok: spoken keywords, on-screen text, concise caption
- Facebook: contextual caption and topic clarity
- Instagram: caption opening, visual relevance, hashtags
- YouTube: title, description, spoken topic, viewer relevance

---

# 18. Content Cluster Rules

Content should strengthen a clear topic category over time.

A content cluster contains:

- One broad pillar
- Several related subtopics
- Repeated audience problems
- Relevant products
- Consistent terminology

Example:

Broad pillar:

- Meal Prep

Subtopics:

- Batch cooking
- Food storage
- Weekly menu planning
- Freezer recipes
- Portion control
- Kitchen tools

Each content asset must focus on one specific subtopic while supporting the broader pillar.

Do not combine too many unrelated topics in one content asset.

---

# 19. Product SEO Rules

When affiliate products are included:

- Use the product category name.
- Mention the use case.
- Mention the relevant feature only when verified.
- Connect the product to the audience's search intent.
- Keep the product secondary to the content value unless the content is a product review.

Preferred structure:

- Problem
- Method
- Product role
- Relevant feature
- CTA

Do not:

- Add unrelated product keywords.
- Use competitor names to attract traffic without relevance.
- Invent product specifications.
- Repeat the product name excessively.
- turn an educational caption into a product keyword list.

---

# 20. Localization Rules

When generating content for a local audience:

- Use the audience's natural search language.
- Use common local terms.
- Avoid literal translations that sound unnatural.
- Preserve product and brand names.
- Use regional terminology when specified.
- Match local spelling and phrasing.

Do not mix languages unless:

- The phrase is commonly used locally.
- The product name requires it.
- The platform convention requires it.
- The content brief explicitly requests it.

---

# 21. Decision Rules

Use the following sequence:

1. Identify the content pillar.
2. Identify the specific topic.
3. Identify the search intent.
4. Select one primary keyword.
5. Select relevant secondary keywords.
6. Select one long-tail keyword when appropriate.
7. Match the keyword set to the actual content.
8. Place keywords naturally.
9. Adapt the copy to the platform.
10. Add relevant hashtags.
11. Verify compliance.
12. Remove unsupported or irrelevant keywords.

If keyword data is unavailable:

- Do not invent search volume.
- Do not claim that a term is trending.
- Use semantic relevance and audience intent.
- Prefer clear long-tail phrases.
- Avoid unsupported ranking promises.

---

# 22. SEO Review Checklist

Before finalizing content, verify:

- Is the main topic clear?
- Is one primary keyword selected?
- Does the keyword match the actual content?
- Does the copy match a clear search intent?
- Is the primary keyword placed naturally?
- Are secondary keywords relevant?
- Is the title accurate?
- Is the caption opening specific?
- Is the description useful?
- Are hashtags relevant?
- Are spoken words, visuals, and metadata aligned?
- Is the product keyword relevant?
- Is the language natural?
- Is keyword repetition controlled?
- Does the content comply with the Compliance Guide?

If any answer is uncertain, revise the SEO elements.

# 23. Output Specification

Every SEO output must include:

- `platform`
- `search_intent`
- `primary_keyword`
- `secondary_keywords`
- `long_tail_keyword`
- `product_keyword`
- `optimized_title`
- `optimized_caption`
- `optimized_description`
- `hashtags`
- `seo_notes`

Example:

```json
{
  "platform": "tiktok",
  "search_intent": "informational",
  "primary_keyword": "overnight oats recipe",
  "secondary_keywords": [
    "easy breakfast",
    "breakfast meal prep",
    "chia seed oats"
  ],
  "long_tail_keyword": "easy overnight oats for busy mornings",
  "product_keyword": "chia seeds",
  "optimized_title": null,
  "optimized_caption": "Easy overnight oats for busy mornings. Add chia seeds for a simple breakfast meal-prep option, then store it overnight. Save this recipe for later.",
  "optimized_description": null,
  "hashtags": [
    "#overnightoats",
    "#breakfastideas",
    "#mealprep",
    "#chiaseeds"
  ],
  "seo_notes": "The primary keyword appears naturally in the opening and is supported by the visual demonstration."
}
```

Every SEO output must be:

- Relevant
- Natural
- Platform-specific
- Search-intent aligned
- Consistent with the Brand Voice
- Compliant
- Free from keyword stuffing
- Ready for publication
